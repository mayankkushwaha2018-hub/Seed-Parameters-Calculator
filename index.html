Metric 01
Germination Percentage
—%
GP = (Σn / N) × 100
⚡
Metric 02
Germination Index
—
GI = Σ(n / d) — Maguire (1962)
Higher value = faster speed
⏳
Metric 03
Mean Germination Time
—days
MGT = Σ(n × d) / Σn
n = germinated/day · d = day no. · Σn = total germinated
📈
Metric 04
Germination Rate Index
—
GRI = G₁/D₁ + G₂/D₂ + … + Gₙ/Dₙ
Gₙ = cumulative germination % up to day n · Dₙ = day number
🌰
Metric 05
Seedling Vigour Index I
—
SVI-I = GP × (Shoot + Root length)
Needs root & shoot length
⚗️
Metric 06
Seedling Vigour Index II
—
SVI-II = GP × Mean seedling dry weight
Needs dry weight (mg)
⏱️
Metric 07
Time to 50% Germination
—days
T₅₀ = tᵢ + [(N/2 − nᵢ)(tⱼ − tᵢ)] / (nⱼ − nᵢ)
N = final germinated seeds · nᵢ = cumulative count just before 50% germination · nⱼ = cumulative count just after 50% germination
